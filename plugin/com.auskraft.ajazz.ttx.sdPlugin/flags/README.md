# Изображения флагов

250 изображений флагов, включая Косово (`xk.png`). Файлы взяты из [набора Flagpedia](https://flagpedia.net/download/images), который опубликован как общественное достояние. По данным Flagpedia, исходные SVG взяты из Wikimedia Commons.

Использован [архив PNG шириной 80 px](https://flagcdn.com/w80.zip) с SHA-256 `04a64630b33105dcebf0b1e25669346e49b8d5ec84f91fa6f60f3d9192f3d03d`. Из архива взяты файлы с двухбуквенными именами. Изображения уменьшены до 64 px по длинной стороне с сохранением пропорций и прозрачности. Они включены в плагин и используются локально.
